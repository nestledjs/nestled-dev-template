## Available Specifications

### 1. Granular RBAC Management
**File:** [granular-rbac-management.md](./granular-rbac-management.md)

**Summary:** Full admin interface for managing roles and permissions, including organization-level custom role creation.

**Use Case:** When organizations need fine-grained access control beyond the default Owner/Admin/Member roles. Includes both super-admin tools for platform operators and organization-level tools for organization owners.

**Complexity:** Medium-High
**Estimated Effort:** 2-3 days
